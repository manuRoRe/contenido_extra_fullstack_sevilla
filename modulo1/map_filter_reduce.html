La cadena de montaje

Transforma, selecciona y resume datos en una línea, sin tocar el original.

Máquina 1

Map — Transforma cada elemento

Si en un array entran 5 elementos, con `map` salen 5 elementos transformados. Devuelve un array nuevo, protegiendo los datos originales.

1

Extraer datos específicos (De for a map)

Pasamos de usar 4 líneas con un bucle `for` y `push` a resolverlo en una sola línea mediante un callback.

JavaScript 
// AYER: 4 líneas (for + push)
const titulos = [];
for (const p of pelis) {
  titulos.push(p.titulo);
}

// HOY: 1 línea con map
const titulos = pelis.map(p => p.titulo);
2

Transformar números (Ejemplo: conversión)

Podemos usar `map` para realizar cálculos matemáticos en todos los elementos de un array a la vez.

JavaScript 
// Tenemos la duración en minutos, queremos verla en horas redondeada
const duracionHoras = pelis.map(p => (p.duracion / 60).toFixed(1));
// Resultado: ["2.8", "1.8", "2.2", ...]
3

De objetos a HTML con map + join

Podemos transformar un array de objetos en un gran bloque de texto HTML para insertarlo en la página.

JavaScript 
lista.innerHTML = pelis
  .map((p, i) => `<li>${i + 1}. ${p.titulo}</li>`)
  .join(""); // Une todos los strings del array
⚠️ No olvides el join("") Si insertas el resultado del map directamente en el HTML sin hacer `.join("")`, aparecerán comas separando cada elemento en la pantalla.
Máquina 2

Filter y Búsquedas — El tamiz

`filter` evalúa cada elemento. Si la función responde `true`, el elemento pasa al nuevo array; si responde `false`, se queda atrás.

1

Filtrar por una o varias condiciones

Puedes aplicar tantas condiciones matemáticas o lógicas como necesites.

JavaScript 
// Una condición simple
const obrasMaestras = pelis.filter(p => p.nota >= 8.5);

// Múltiples condiciones (Ej: Animación moderna)
const animacionReciente = pelis.filter(p => p.genero === "animación" && p.anio > 2014);
// Devuelve: [{titulo: "Coco"...}, {titulo: "Del revés"...}]
2

Encadenar métodos (Chaining)

Podemos encadenar métodos como una receta de arriba a abajo. El orden es fundamental.

JavaScript 
const dramas = pelis
  .filter(p => p.genero === "drama") // 10 objetos → 3 objetos
  .map(p => p.titulo)              // 3 objetos → 3 textos
  .join(", ");                       // "Parásitos, Whiplash, Joker"
⚠️ El orden importa Si haces el `map` antes para extraer el título, en el siguiente paso ya no tendrás el objeto completo y no podrás filtrar por género.
3

Otros métodos de búsqueda

Método Para qué sirve Devuelve
find Busca el primer elemento que cumple la condición y se detiene. El elemento, o undefined si no hay.
findIndex Busca la posición (índice) del primer elemento que cumple. Un número, o -1 si no hay.
some Pregunta si algún elemento cumple la condición. true o false.
every Pregunta si todos los elementos cumplen la condición. true o false.
Concepto Clave

Funciones Puras y Mutabilidad

1

Función Pura vs Impura

Una función pura es como una calculadora: para un mismo input, siempre devuelve el mismo output, y solo usa sus parámetros sin alterar el exterior. Una función impura produce efectos secundarios (cambia variables externas, muta el array recibido, altera el DOM o usa herramientas como `Math.random`).

2

¿Este método cambia el original?

MUTAN (⚠️ Peligro) NO MUTAN (✅ Seguro)
push, pop, shift, unshift, splice, sort, reverse map, filter, reduce, slice, concat, join, toSorted

La trampa de sort: Si ejecutas `[10, 9, 2].sort()`, ¿qué resultado obtienes?

💡 Solución a sort y reverse Para ordenar números correctamente sin mutar el original, haz primero una copia con `slice()` y pásale un comparador:
nums.slice().sort((a, b) => a - b)
Máquina 3

Reduce — La bola de nieve

`reduce` resume todos los elementos de un array en un único valor (un total, un objeto agrupado, o el mejor elemento).

1

Sumar totales (El acumulador)

JavaScript 
// acc es lo acumulado, p es el elemento actual. 0 es el valor inicial.
const duracionTotal = pelis.reduce((acc, p) => acc + p.duracion, 0);
⚠️ Pon siempre el valor inicial Si omites el `0` al sumar objetos, el primer valor (acc) será el primer objeto entero, rompiendo la suma.
2

Encontrar al "campeón" (Reduce sin valor inicial)

A veces no queremos sumar, sino que los elementos "compitan" entre ellos y quedarnos con uno (ej. el de mejor nota).

JavaScript 
// Si no pasamos valor inicial, 'acc' (mejor) empieza siendo la 1ª peli
const mejorPeli = pelis.reduce((mejor, p) => p.nota > mejor.nota ? p : mejor);
// En cada vuelta compara: si la actual tiene mejor nota, se convierte en la nueva ganadora.
3

Contar y agrupar (Objetos dinámicos)

Si el valor inicial es un objeto vacío `{}`, puedes ir construyendo un diccionario con totales por categoría.

JavaScript 
const porGenero = pelis.reduce((acc, p) => {
  acc[p.genero] = (acc[p.genero] || 0) + 1;
  return acc; // ¡Crucial devolver el acumulador en cada vuelta!
}, {}); // Empieza vacío
// Resultado: { "ciencia ficción": 3, "animación": 3, ... }
Flujo de datos

Estado → render() → DOM

1

Separación de responsabilidades

Nuestras funciones de filtrado, cálculo de medias o conteo deben ser puras (reciben datos, devuelven datos). La única función encargada de tocar el DOM es render().

JavaScript 
buscar.addEventListener("input", (e) => {
  // 1. Cambia el estado
  filtros.texto = e.target.value; 
  
  // 2. Repinta TODO llamando a la función impura
  render(); 
});
Resumen

Chuleta de arrays

Transformar
map(fn)

Array del mismo tamaño. No muta.

Seleccionar
filter(fn)

Quedarse con algunos. No muta.

Resumir
reduce(fn, inicial)

Resume en un único valor. No muta.

Buscar
find(fn) · findIndex(fn)

El primero que cumple (o su índice).

Comprobar
some(fn) · every(fn)

¿Alguno o Todos? Devuelve true/false.

Copiar y Ordenar
slice().sort(fn)

Para no mutar el original.
