Parte 1

Objetos — Fichas de datos

Un objeto es una colección de datos agrupados como una ficha, mediante pares de clave → valor. El valor puede ser texto, números, arrays e incluso otros objetos.

1

Estructura de un Objeto

Un objeto se define con llaves {}. Cada propiedad tiene una etiqueta (la clave) y su dato (el valor).

JavaScript
const peli = {
  titulo: "Interstellar",
  anio: 2014,
  generos: ["sci-fi", "drama"],
  director: { nombre: "Nolan" },
  vista: true
};
2

Leer, añadir y modificar (El punto es un camino)

Usamos un punto . para acceder a las propiedades si sabemos su nombre. Si la clave está en una variable, usamos corchetes [].

JavaScript
// Leer un dato anidado
console.log(peli.director.nombre); // "Nolan"

// Leer con una variable
let campo = "titulo";
console.log(peli[campo]); // "Interstellar"

// Añadir nueva propiedad
peli.nota = 8.7;

// Modificar una existente
peli.vista = false;

// Eliminar
delete peli.director;
3

Métodos y `this`

Un método es una función que vive dentro de un objeto. Usamos this para referirnos al propio objeto (lo que está a la izquierda del punto al llamar al método).

JavaScript
const alumno = {
  nombre: "Lucía",
  saludar() {
    return `Hola, soy ${this.nombre}`;
  }
};

console.log(alumno.saludar()); // "Hola, soy Lucía"
Parte 2

JSON — El objeto convertido en texto para viajar

Para guardar un objeto o enviarlo por internet, necesitamos convertirlo en un string de texto. Esto es JSON (JavaScript Object Notation).

Característica Objeto JS JSON
Clavestitulo"titulo" (siempre con comillas dobles)
Textos'...' o "..."Solo "..."
Funciones✅ Sí❌ No
1

Convertir: JSON.stringify y JSON.parse

JavaScript
const obj = { titulo: "Coco" };

// Para ENVIAR o GUARDAR (de objeto a string)
const texto = JSON.stringify(obj);
console.log(texto); // '{"titulo":"Coco"}'

// Al RECIBIR o LEER (de string a objeto)
const recuperado = JSON.parse(texto);
console.log(recuperado.titulo); // "Coco"
Parte 3

Arrow Functions — Sintaxis reducida

Las arrow functions (funciones flecha) son una forma más corta de escribir funciones. Son especialmente útiles para pasarlas a otras funciones como "callbacks".

1

De `function` a flecha en 3 pasos

JavaScript
// Punto de partida
function doble(n) { return n * 2; }

// 1. Fuera 'function', entra '=>'
const doble = (n) => { return n * 2; };

// 2. Una línea: fuera llaves y 'return' implícito
const doble = (n) => n * 2;

// 3. Un solo parámetro: fuera paréntesis
const doble = n => n * 2;
⚠️ Devolver un objeto en una línea Para devolver un objeto sin usar `return`, debes envolverlo en paréntesis. Si usas llaves directamente, JS pensará que es el cuerpo de la función.
n => { nombre: n } // Mal ❌ (devuelve undefined)
n => ({ nombre: n }) // Bien ✅ (devuelve un objeto)
2

El problema de `this` léxico

Las arrow functions no tienen su propio valor de this. Heredan el this del contexto donde se escribieron, por lo que **no deben usarse como métodos de un objeto**.

JavaScript
const persona = {
  nombre: "Ana",
  // Bien: sintaxis clásica (this es 'persona')
  saludo1() { return this.nombre; }, 
  
  // Mal: arrow function (this heredado, será 'window' o 'undefined')
  saludo2: () => this.nombre 
};
💡 Regla de oro: Usa la sintaxis clásica para métodos de objeto. Usa arrow functions para callbacks (funciones que pasas a otras, como en setTimeout o addEventListener).
Parte 4

El DOM — Del HTML al Árbol

JavaScript no manipula el archivo .html original. Al cargar la página, el navegador crea en memoria un árbol de objetos (el Document Object Model). Tú tocas el DOM con JS y el navegador repinta la pantalla.

1

Seleccionar Elementos: querySelector(All)

Usamos los mismos selectores que en CSS (.clase, #id, etiqueta) para buscar elementos en el árbol.

JavaScript
// Busca el PRIMER elemento que coincide
const titulo = document.querySelector("#titulo");
const primerMensaje = document.querySelector(".mensaje");

// Busca TODOS los que coinciden (devuelve un NodeList)
const todosMensajes = document.querySelectorAll(".mensaje");

// Puedes usar forEach en un NodeList
todosMensajes.forEach(msg => msg.classList.add("leido"));
⚠️ NodeList no es exactamente un Array Aunque tiene forEach, no tiene map, filter o reduce. Si los necesitas, conviértelo: Array.from(document.querySelectorAll("p")).
2

Escribir y modificar el DOM

Hay varias propiedades importantes para interactuar con el contenido de un elemento.

PropiedadUso principalSeguridad
textContentInsertar texto plano. Las etiquetas HTML se muestran como texto sin renderizar.🔒 Seguro. Usar por defecto para contenido del usuario.
innerHTMLInsertar texto e interpretar el HTML interno (ej: <b>negrita</b>).⚠️ Peligroso (XSS). Nunca usar con datos no confiables.
valueLeer o escribir el contenido de campos de formulario (inputs, textareas).—
datasetLeer datos anclados al HTML con data-* (ej: data-id="42" → el.dataset.id).—
3

Clases CSS (classList)

En lugar de tocar estilos a mano con JS, es mejor usar JS para poner/quitar clases y dejar que CSS haga su trabajo.

JavaScript
const body = document.body;

body.classList.add("oscuro");      // Poner clase
body.classList.remove("oscuro");   // Quitar clase
body.classList.toggle("oscuro");   // Interruptor: si la tiene la quita, si no la pone
console.log(body.classList.contains("oscuro")); // true/false
4

Crear nodos dinámicamente

Para añadir un nuevo elemento a la página son necesarios 3 pasos.

JavaScript
// 1. CREAR (Existe en memoria, no se ve)
const li = document.createElement("li");

// 2. CONFIGURAR (Añadir texto, clases...)
li.textContent = "Interstellar";
li.classList.add("pelicula");

// 3. COLGAR (Aparece en la página al añadirlo a un elemento padre)
const lista = document.querySelector("ul");
lista.append(li); // Lo coloca al final (prepend lo coloca al principio)

El BOM — El Navegador Global

Si el DOM es la página document, el BOM (Browser Object Model) es el navegador entero representado por el objeto window. Lo incluye todo, incluso al propio document.

1

Propiedades útiles del objeto `window`

Objeto/MétodoPara qué sirve
window.innerWidthAnchura de la ventana en píxeles.
window.locationEl enlace actual (href, hostname). Puedes hacer location.reload().
window.navigatorInformación del sistema: idioma, estado de conexión.
alert() / prompt()Diálogos del navegador. Como están dentro de window, puedes llamar a alert() directamente en vez de window.alert().
setTimeout(fn, ms)Llama a la función fn UNA SOLA VEZ pasados ms milisegundos.
setInterval(fn, ms)Llama a la función fn REPETIDAMENTE cada ms milisegundos hasta usar clearInterval().
Parte 6

Eventos — La página reacciona al usuario

Los eventos ocurren cuando el usuario interactúa (hace click, pulsa una tecla, envía un formulario). Nosotros "escuchamos" y reaccionamos a ellos usando addEventListener.

1

Escuchar con addEventListener

Recibe dos cosas: qué evento escuchar y qué función ejecutar (un callback). Esta función recibirá automáticamente un objeto evento (e o event).

JavaScript
const boton = document.querySelector("button");

// Escucha al evento 'click', al suceder ejecuta la arrow function
boton.addEventListener("click", (e) => {
  document.body.classList.toggle("oscuro");
  console.log("Hiciste click en: ", e.target);
});
Tipos de eventos comunes: click (pulsar), input (escribir cada tecla en un campo), submit (enviar un form), keydown (teclado).
2

Formularios y preventDefault()

Por defecto, enviar un formulario recarga la página instantáneamente. Para manejar los datos sin perder el estado de JavaScript, cancelamos este comportamiento con e.preventDefault().

JavaScript
const form = document.querySelector("form");
const input = document.querySelector("input");

form.addEventListener("submit", (e) => {
  e.preventDefault(); // ¡Crucial! Evita que se recargue la web.
  
  const nombre = input.value.trim();
  console.log("Se envió: " + nombre);
  
  form.reset(); // Vacía los campos
});
3

Delegación de eventos

Los eventos "burbujean" hacia arriba: un clic en un li sube hacia el ul. En lugar de poner listeners en 100 li (y tener que ponerlos de nuevo al añadir nuevos items), ponemos **un solo listener en el ul padre**.

JavaScript
const lista = document.querySelector("ul");

lista.addEventListener("click", (e) => {
  // 'e.target' es exactamente donde hicimos clic (ej. un  o la 'X')
  // 'closest' busca hacia arriba el primer elemento que encaje, o null.
  const itemLi = e.target.closest("li");
  
  if (itemLi) {
    // Sabemos qué Li se tocó.
    console.log("Tocaste la tarea:", itemLi.textContent);
  }
});
