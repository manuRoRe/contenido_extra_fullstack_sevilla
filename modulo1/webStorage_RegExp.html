Parte 1

localStorage — el cajón del navegador

Hasta ahora, todo lo que guardabas en JavaScript desaparecía al recargar la página. localStorage es un espacio de almacenamiento que el navegador guarda en disco: sobrevive a recargas e incluso a cerrar el navegador.

¿Cómo funciona? Es un almacén de clave → valor, uno por origen (protocolo + dominio + puerto). Tiene unos 5 MB y solo guarda texto. Nunca guardes contraseñas ni tokens aquí: cualquier script de la página puede leerlo.
1

Los cuatro métodos básicos

Toda la API de localStorage son cuatro métodos. Cópialo en la consola del navegador y pruébalos uno a uno.

JavaScript
// Guardar
localStorage.setItem("ciudad", "Madrid");

// Leer
const ciudad = localStorage.getItem("ciudad");
console.log(ciudad); // "Madrid"

// Leer una clave que no existe → null
console.log(localStorage.getItem("noexiste")); // null

// Borrar una clave
localStorage.removeItem("ciudad");

// Borrar TODO (¡con cuidado!)
localStorage.clear();
⚠️ Todo entra y sale como texto Aunque guardes el número 42, al leerlo obtendrás el string "42".
localStorage.setItem("num", 42) → typeof localStorage.getItem("num") // "string"
2

Verificar en el navegador

Abre las DevTools con F12, ve a la pestaña Application y en el panel izquierdo encontrarás Local Storage. Puedes ver, editar y borrar claves ahí mismo.

💡 Prueba offline En DevTools → Network, pon el modo "Offline", recarga la página y comprueba que los datos siguen en localStorage aunque no haya conexión.
Parte 2

JSON — guardar objetos y arrays

Como localStorage solo guarda texto, necesitamos convertir nuestros objetos y arrays a texto (JSON) antes de guardarlos, y volver a convertirlos al leerlos.

1

El problema: guardar un objeto directamente

JavaScript
// ❌ MAL: guarda el objeto tal cual
localStorage.setItem("pelicula", { id: 1, titulo: "Coco" });
localStorage.getItem("pelicula"); // "[object Object]" 😱
2

La solución: JSON.stringify y JSON.parse

JavaScript
const peli = { id: 1, titulo: "Coco", anio: 2017 };

// ✅ BIEN: convertir a texto antes de guardar
localStorage.setItem("pelicula", JSON.stringify(peli));

// Leer: convertir el texto de vuelta a objeto
const texto = localStorage.getItem("pelicula");
const recuperado = JSON.parse(texto);

console.log(recuperado.titulo); // "Coco"
3

El patrón completo: leer con seguridad

La primera vez que alguien abre la app, no hay nada guardado. getItem devuelve null, y JSON.parse(null) también devuelve null. Usamos ?? para devolver un array vacío como fallback.

JavaScript
// Función reutilizable para leer de localStorage
function leerJSON(clave, valorPorDefecto = []) {
  try {
    const texto = localStorage.getItem(clave);
    return JSON.parse(texto) ?? valorPorDefecto;
  } catch {
    // Si el JSON está roto (alguien lo editó a mano), devuelve el defecto
    return valorPorDefecto;
  }
}

// Guardar una lista de favoritos
const CLAVE = "miapp:favoritos";
const favoritos = [{ id: 603, titulo: "Matrix" }];
localStorage.setItem(CLAVE, JSON.stringify(favoritos));

// Leer favoritos (si no hay nada, devuelve [])
const guardados = leerJSON(CLAVE);
console.log(guardados); // [{ id: 603, titulo: "Matrix" }]
💡 Prefijos en las claves Usa un prefijo como "miapp:" para evitar colisiones con otras apps que compartan el mismo origen (por ejemplo, todos los proyectos de localhost).

Parte 3

Reconstruir instancias de clase

Cuando guardas una instancia de clase en localStorage con JSON.stringify, se guardan los datos pero se pierden los métodos. Al leer, necesitas reconstruir la instancia.

1

El problema: stringify pierde los métodos

JavaScript
class Pelicula {
  constructor({ id, titulo, anio, nota }) {
    this.id    = id;
    this.titulo = titulo;
    this.anio  = anio;
    this.nota  = nota;
  }
  toCard() {
    return `<div class="card">${this.titulo} (${this.anio})</div>`;
  }
}

const peli = new Pelicula({ id: 1, titulo: "Coco", anio: 2017, nota: 8.2 });

// Guardar
localStorage.setItem("peli", JSON.stringify(peli));

// Leer → objeto plano, sin toCard()
const plano = JSON.parse(localStorage.getItem("peli"));
plano.toCard(); // ❌ TypeError: plano.toCard is not a function
2

La solución: reconstruir con new

Como el constructor acepta un objeto con los mismos nombres, reconstruir es una sola línea con .map().

JavaScript
function leerFavoritos() {
  // 1. Leer del storage (array de objetos planos)
  const planos = leerJSON("miapp:favoritos", []);
  // 2. Reconstruir instancias con new Pelicula(objeto)
  return planos.map(obj => new Pelicula(obj));
}

function guardarFavoritos(favoritos) {
  // stringify convierte las instancias a objetos planos automáticamente
  localStorage.setItem("miapp:favoritos", JSON.stringify(favoritos));
}

// ✅ Ahora sí funcionan los métodos
const favoritos = leerFavoritos();
favoritos[0]?.toCard(); // funciona 🎉
3

Alternar un favorito (añadir/quitar)

JavaScript
function alternarFavorito(id, todasLasPelis) {
  let favoritos = leerFavoritos();
  const yaEsFav = favoritos.some(f => f.id === id);

  if (yaEsFav) {
    // Quitar: filter crea un nuevo array sin esa película
    favoritos = favoritos.filter(f => f.id !== id);
  } else {
    // Añadir: spread + la nueva al final
    const peli = todasLasPelis.find(p => p.id === id);
    favoritos = [...favoritos, peli];
  }

  guardarFavoritos(favoritos); // persistir
  return favoritos;             // devolver para re-pintar
}
Parte 4

sessionStorage — solo mientras dura la pestaña

Misma API que localStorage, pero los datos desaparecen cuando se cierra la pestaña. Ideal para guardar el estado temporal de la sesión (última búsqueda, filtros activos…).

Característica localStorage sessionStorage
Sobrevive a recargar✅ Sí✅ Sí
Sobrevive a cerrar pestaña✅ Sí❌ No
Compartido entre pestañas✅ Sí❌ No, cada pestaña tiene el suyo
Caso de uso típicoFavoritos, historialÚltima búsqueda, paso de un wizard
1

Ejemplo: recordar la última búsqueda

JavaScript
const CLAVE_BUSQUEDA = "miapp:ultimaBusqueda";

function guardarUltimaBusqueda(texto) {
  sessionStorage.setItem(CLAVE_BUSQUEDA, texto);
}

function recuperarUltimaBusqueda() {
  return sessionStorage.getItem(CLAVE_BUSQUEDA) ?? "";
}

// Al cargar la página, recuperar la búsqueda anterior
const busqueda = recuperarUltimaBusqueda();
if (busqueda) {
  inputBusqueda.value = busqueda;  // rellenar el campo
  buscar(busqueda);               // repetir la búsqueda
}
💡 Pruébalo Busca algo, recarga la página → sigue. Cierra la pestaña y abre una nueva → ha desaparecido. Abre dos pestañas → cada una tiene su propia última búsqueda.
2

Historial de búsquedas (las últimas 5, sin repetir)

JavaScript
function leerHistorial() {
  return leerJSON("miapp:historial", []);
}

function anadirAlHistorial(texto) {
  // 1. Quitar si ya estaba (comparando sin importar mayúsculas)
  const anteriores = leerHistorial()
    .filter(t => t.toLowerCase() !== texto.toLowerCase());

  // 2. Poner la nueva al principio
  // 3. Quedarse solo con las 5 primeras
  const nuevo = [texto, ...anteriores].slice(0, 5);

  localStorage.setItem("miapp:historial", JSON.stringify(nuevo));
  return nuevo; // devolver para pintar los chips
}

// Prueba: busca "dune", "matrix", "coco", luego "Matrix" de nuevo
// Resultado: ["Matrix", "coco", "dune"]  ← Matrix reemplazó a matrix
Parte 5

RegExp — expresiones regulares

Una expresión regular es un patrón que describe la forma que debe tener un texto. Se usa para validar entradas, buscar, extraer y reemplazar partes de strings.

1

Anatomía de una expresión regular

Lectura de izquierda a derecha: /^[a-záéíóúüñ0-9 ]{2,60}$/i
→ "de principio a fin, entre 2 y 60 letras, números o espacios, sin importar mayúsculas"
PiezaSignificadoEjemplo
^Inicio del texto^Hola → empieza por "Hola"
$Final del textofin$ → termina en "fin"
[a-z]Rango de caracteres[a-z0-9]
\dUn dígito (0-9)\d{4} → año de 4 dígitos
\sUn espacio en blanco\s+ → uno o más espacios
{2,60}Entre 2 y 60 veces[a-z]{2,60}
+1 o más veces\d+ → uno o más dígitos
*0 o más vecesa*
?0 o 1 vez (opcional)colou?r
( )Grupo capturador(\d{4})
iFlag: ignora mayúsculas/hola/i → "HOLA", "hola"
gFlag: busca todas las coincidencias/\s+/g
2

Los cuatro métodos más útiles

JavaScript
// ── test: ¿cumple el patrón? → true/false ──
const esValida = /^[a-záéíóúüñ0-9 ]{2,60}$/i.test("Matrix");
console.log(esValida); // true
/^[a-záéíóúüñ0-9 ]{2,60}$/i.test("x"); // false (solo 1 carácter)
/^[a-záéíóúüñ0-9 ]{2,60}$/i.test("<script>"); // false

// ── replace: sustituir coincidencias ──
const limpio = "  the   matrix  "
  .trim()              // quitar espacios al inicio y final
  .replace(/\s+/g, " "); // colapsar espacios múltiples a uno
console.log(limpio); // "the matrix"

// ── match: extraer partes del texto ──
const anio = "Dune (2021)".match(/\d{4}/)[0];
console.log(anio); // "2021"

// ── split con grupo: separar conservando el separador ──
const partes = "Toy Story 2".split(/(Story)/i);
console.log(partes); // ["Toy ", "Story", " 2"]
//                         par     impar    par  ← posiciones
3

Validar y limpiar una búsqueda

JavaScript
const PATRON_BUSQUEDA = /^[a-záéíóúüñ0-9 ]{2,60}$/i;

function limpiarBusqueda(texto) {
  return texto.trim().replace(/\s+/g, " ");
}

function esBusquedaValida(texto) {
  return PATRON_BUSQUEDA.test(texto);
}

// En el submit del formulario de búsqueda:
function alBuscar(textoBruto) {
  const texto = limpiarBusqueda(textoBruto);

  if (!esBusquedaValida(texto)) {
    inputBusqueda.classList.add("error"); // barra roja
    return; // ❌ no gastar petición ni ensuciar el historial
  }

  inputBusqueda.classList.remove("error");
  anadirAlHistorial(texto);
  buscarEnAPI(texto); // ✅ solo si es válido
}

Parte 6

Resaltar texto buscado — sin innerHTML

Cuando el usuario busca "Matrix" queremos que aparezca resaltado en los resultados. El truco está en split con un grupo capturador, y en usar textContent en vez de innerHTML por seguridad.

⚠️ ¿Por qué no innerHTML? Los títulos vienen de una API externa. Si alguno contiene <img onerror="alert(1)">, usar innerHTML ejecutaría ese código. Con textContent, se muestra como texto puro, nunca se ejecuta.
1

Cómo funciona split con grupo capturador

JavaScript
// Sin grupo: el separador desaparece
"The Matrix Reloaded".split(/matrix/i);
// → ["The ", " Reloaded"]

// CON grupo (): el separador se conserva en posiciones impares
"The Matrix Reloaded".split(/(matrix)/i);
// → ["The ", "Matrix", " Reloaded"]
//      [0]      [1]        [2]
//     par     impar       par   ← pares = texto normal, impares = coincidencia
2

Escapar el texto del usuario antes de usarlo en RegExp

Si el usuario busca "(500) días", los paréntesis tienen significado en RegExp. Hay que escaparlos.

JavaScript
function escaparRegExp(texto) {
  // Añade \ antes de cada carácter especial de RegExp
  return texto.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}

// Sin escapar: /((500) días)/gi → error o comportamiento raro
// Con escapar:  /(\(500\) días)/gi → correcto
console.log(escaparRegExp("(500) días")); // "\(500\) días"
3

La función completa para resaltar

JavaScript
function resaltarTexto(contenedor, titulo, buscado) {
  contenedor.innerHTML = ""; // vaciar el contenedor

  if (!buscado) {
    contenedor.textContent = titulo; // sin búsqueda, texto normal
    return;
  }

  // Crear RegExp dinámica con el texto del usuario (escapado)
  const patron = new RegExp(`(${escaparRegExp(buscado)})`, "gi");
  const partes = titulo.split(patron);

  partes.forEach((parte, i) => {
    if (i % 2 === 0) {
      // Posición par → texto normal
      contenedor.appendChild(document.createTextNode(parte));
    } else {
      // Posición impar → coincidencia → envolver en <mark>
      const mark = document.createElement("mark");
      mark.textContent = parte; // textContent, nunca innerHTML
      contenedor.appendChild(mark);
    }
  });
}

// Uso:
// <h3 class="titulo-card"></h3>
const h3 = document.querySelector(".titulo-card");
resaltarTexto(h3, "The Matrix Reloaded", "matrix");
// Resultado visual: The <mark>Matrix</mark> Reloaded
