Parte 1

El Plano y la Fábrica: Clases e Instancias

Copiar y pegar objetos repetidamente genera erratas mudas y código difícil de mantener. Una clase actúa como un plano o molde (*blueprint*) para fabricar múltiples instancias con propiedades y métodos compartidos.

1

Anatomía de una clase y el constructor

El método constructor es el motor de arranque que se ejecuta automáticamente al invocar la clase con new. Recibe los datos y los asigna al contexto de la instancia usando this.

JavaScript
class Pelicula {
  constructor(titulo, anio, duracion = 90) {
    this.titulo = titulo;
    this.anio = anio;
    this.duracion = duracion;
    this.vista = false;
  }

  // Método compartido en el prototipo
  ficha() {
    return `${this.titulo} (${this.anio})`;
  }
}

const coco = new Pelicula("Coco", 2017, 105);
2

¿Qué hace exactamente la palabra `new` paso a paso?

PasoAcción interna
1Crea un objeto literal vacío { }.
2Conecta ese objeto al prototipo de la clase (enlace [[Prototype]]).
3Ejecuta el constructor rellenando las propiedades mediante this.
4Devuelve automáticamente el objeto resultante (sin necesidad de escribir return).
Parte 2

Interfaz Controlada: Getters y Setters

Los métodos get y set actúan como puertas de seguridad que permiten calcular valores o validar datos al leerlos o modificarlos como si fueran propiedades simples.

1

Uso de Getters (Calculadoras) y Setters (Porteros)

JavaScript
class Pelicula {
  constructor(titulo, duracion) {
    this.titulo = titulo;
    this.duracion = duracion;
  }

  // Getter: se llama sin paréntesis (ej: peli.horas)
  get horas() {
    return (this.duracion / 60).toFixed(1) + " h";
  }
}

const inter = new Pelicula("Interstellar", 169);
console.log(inter.horas); // "2.8 h"
Parte 3

Evolución Estructural: Herencia (`extends`)

La herencia responde a la regla lógica del "es un" (una serie es un tipo de contenido multimedia heredado de la clase base).

1

Extender clases con `extends` y `super()`

Al crear una clase hija, es obligatorio invocar a super() en el constructor antes de utilizar la palabra this.

JavaScript
class Serie extends Pelicula {
  constructor(titulo, anio, duracion, temporadas) {
    super(titulo, anio, duracion); // Llama al constructor de la madre
    this.temporadas = temporadas;  // Propiedad exclusiva de la hija
  }

  // Sobrescribir / ampliar un método
  ficha() {
    return `${super.ficha()} · ${this.temporadas} temporadas`;
  }
}
Parte 4

Proyecto CineData: La Tubería de Datos (API → Clases → DOM)

En aplicaciones reales, los datos crudos de una API (como TMDB) suelen ser caóticos, venir con campos nulos o formatos no amigables. Transformamos ese JSON en instancias seguras mediante POO.

1

El Constructor como Digestor y Fallbacks

JavaScript
class Movie {
  constructor(data) {
    this.id = data.id;
    this.title = data.title;
    this.releaseDate = data.release_date;
    this.score = data.vote_average;
    
    // Fallback ternario si la API devuelve una imagen nula
    this.poster = data.poster_path 
      ? `https://image.tmdb.org/t/p/w500${data.poster_path}` 
      : 'default-poster.jpg';
  }

  get year() {
    return this.releaseDate ? this.releaseDate.split('-')[0] : 'Desconocido';
  }

  // Generación de HTML encapsulado
  toCard() {
    return `
      <article class="movie-card" id="${this.id}">
        <img src="${this.poster}" alt="${this.title}">
        <div class="content">
          <h2>${this.title} (${this.year})</h2>
          <p>⭐ ${this.score}</p>
        </div>
      </article>
    `;
  }
}
2

Transformar el array crudo con .map()

Convertimos el listado plano de la API en un batallón de instancias equipadas con métodos y getters seguros.

JavaScript
const movieInstances = rawArray.map(data => new Movie(data));
container.innerHTML = movieInstances.map(movie => movie.toCard()).join('');
Resumen

Chuleta de Clases y POO

class
class Pelicula { ... }

Define el molde o plano estructural.

constructor
constructor(val) { this.val = val }

Inicializa los atributos de cada instancia.

new
const p = new Pelicula(...)

Fabrica un objeto físico a partir del molde.

get / set
get prop() { return ... }

Calcula propiedades al vuelo sin paréntesis.

extends / super
class Serie extends Pelicula

Herencia de clases y llamada a la madre.

static
static desdeObjeto(o)

Método de utilidad ejecutado sobre la clase.
